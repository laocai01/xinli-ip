## 二、两条线的人群与定位

### 线路 A · 情绪自救型
> **一句话定位：帮你搞定你自己。**

| 项 | 内容 |
|---|---|
| **针对人群** | **自己跟自己过不去的人** |
| 典型画像 | 想太多、内耗、焦虑、失眠、自我攻击、拖延、越躺越丧 |
| 痛点场景 | **独处时痛**：睡前、一个人呆着、深夜刷手机 |
| 观众心理 | "这说的就是我" |
| 内容基调 | **共鸣型** —— 先让你觉得被看见，再给你一个能做的小动作 |
| 卡片色系 | **米黄暖色**（现有这套，安抚感） |
| 知识库弹药 | 情绪 12 + 职场 12 + 自我成长 14 = **38 条** |
| 主打流派 | CBT认知行为 / ACT正念 / DBT / 森田 / 积极心理学 |

### 线路 B · 关系修复型
> **一句话定位：帮你搞定你和别人的事。**

| 项 | 内容 |
|---|---|
| **针对人群** | **自己跟别人过不去的人** |
| 典型画像 | 跟伴侣吵、跟孩子拧、婆媳夹心、职场人际卡壳 |
| 痛点场景 | **相处时痛**：刚吵完、冷战中、说了伤人的话之后 |
| 观众心理 | "这说的是我们" |
| 内容基调 | **解决型** —— 先指出现象，再给一句能立刻用的话术/动作 |
| 卡片色系 | **冷色系**（深青/墨绿，理性冷静）← 待做 |
| 知识库弹药 | 关系 13 + 亲子 14 = **27 条** |
