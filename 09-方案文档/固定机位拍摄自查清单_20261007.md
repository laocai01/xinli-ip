# 「老蔡说」固定机位拍摄自查清单

> 用途：董事长位置固定、不动场景，只做**摆灯/摆物**的微调。拍前 5 分钟核对一遍。
> 依据：实测原片（桌面 1.mp4）+ 全网拍摄实操规范。**不花钱、不挪位置。**

---

## 一、核心原理（一句话）

**观众第一眼看"画面里最亮的东西"。** 现在你的背景白墙（亮度 220）比你的脸（195）亮
→ **观众先看墙，不看人** → 算法判"低质画面" → 推荐权重压低。

**目标：让人比背景亮、让人从背景里"跳"出来。**

---

## 二、拍前 5 分钟检查表（逐条打勾）

### 光（最重要，占效果 70%）

- [ ] **关掉头顶的吸顶灯**（顶光会在脸上投阴影，且把背景照得比人亮）
- [ ] **台灯（或手机补光灯）放在你左前方或右前方约 45°**，灯头朝你的脸
      - 有柔光罩最好；没有就用**一张白纸蒙在灯前**柔化光线
- [ ] **手机屏幕里眯眼看**：第一眼看到的是你的脸，不是墙 → 及格
- [ ] **脸上不能有"眼窝黑洞"**（头顶灯造成的）→ 有就重调灯位

### 背景（让背景比人暗、有层次）

- [ ] **关掉照墙的那盏灯**（如果背景比人亮）
- [ ] 墙太亮挡不住？→ 在**灯和墙之间**放个东西挡光（挂件衣服/靠本书/一块深色布）
- [ ] **身后加一样点缀物**，制造空间感。三选一：
      - 一幅挂画 / 一张日历（贴在画面**边缘**，别正对你头顶）
      - 挂在墙上的衣服 / 包
      - 一盆绿植（放在画面边缘，占画面 10-15%）
- [ ] **别用纯白当唯一背景** —— 白墙是最容易被算法判"低质"的

### 位置与构图

- [ ] 人**不要死卡画面正中** → 站/坐偏左或偏右一点（三分之一线附近）
- [ ] **头顶留白** ≈ 画面高度的 1/6（别顶框、别太空）
- [ ] **镜头高度＝眼睛高度**（平视，不仰不俯）
- [ ] 手机**开网格线**，背景的竖线（门框/柜子）和画面边平行 → 歪了显得不专业

### 服装

- [ ] 别穿纯白（和白墙融在一起，人就"没了"）
- [ ] 别穿和背景同色系
- [ ] **推荐：深色 / 中灰 / 藏蓝 / 酒红** —— 和白墙形成对比，人立刻跳出来

---

## 三、最省事的见效顺序

**如果只做一件事** → 把灯放侧前方 45°，关顶灯。
**如果做两件事** → 加上"换深色上衣"。
**如果做三件事** → 再加"身后墙上挂/贴一样东西"。

---

## 四、拍完自检（录 10 秒回放，问自己）

1. **第一眼看的是我的脸，还是墙？** → 必须是脸
2. **我脸上有阴影吗？** → 不能有眼窝黑洞
3. **背景是死平一片，还是有东西？** → 要有一点层次
4. **我和背景糊在一起了吗？** → 我必须要"跳出来"
5. **画面里有没有在动/在闪的东西？**（空调吹窗帘、电视待机） → 有就处理掉

---

## 五、附：为什么"换虚拟背景"不推荐（技术判断）

| 方案 | 问题 |
|---|---|
| AI 抠像换背景 | 边缘发虚、发丝被吃、人像"贴纸感" —— 正是"人模糊/不真实"的来源 |
| 绿幕拍摄 | 需要布、灯、空间，且溢色会染到衣服和头发边缘 |
| **实景 + 打光（本清单方案）** | **人最真实、最清晰，零成本，不动位置** ✅ |

**结论：固定机位下，先把"光"和"人物与背景的分离"做好，比换任何背景都有效。**
