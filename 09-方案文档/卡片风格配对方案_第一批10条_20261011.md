# 《老蔡说》第一批 10 条 · 卡片风格配对方案

配对原则：**风格的情绪 = 内容的情绪**。不是好看就行，是"画面要替内容说话"。

## 三条线的内容气质

| 线路 | 讲什么 | 整体气质 | 排除的风格 |
|---|---|---|---|
| **A 没人可说** | 中年人自己的累、孤独、憋 | 深夜、沉、一个人 | 亮飘的、太甜的 |
| **B 我是不是没用了** | 退休、空、被需要 | 空落、旧、温度 | 寒凉冰冷的、刺的 |
| **C 你根本不了解我** | 亲子、孩子不说话 | 柔、耐心、靠近 | 冷硬的、重的 |

## 逐条配对

### 00 过渡片 · 我讲了好几期今天说件事
**内容**：坦白讲错了、重新开三块（自己 / 家里人 / 孩子），是新开篇。
**感觉**：**开场、明亮、重新出发**。

| 序 | 风格 | 为什么配 |
|---|---|---|
| 主 | **92 亮彩柔光** | 亮、暖、开阔 → "重新开始" |
| 副 | **88 云白叠层** | 干净、有层次 → "讲清楚三块" |
| 收 | **94 亮色几何** | 活泼几何 → "三个板块"分块感 |
| 备 | **69 卡片列递退** | 一叠卡 = 一季内容铺开 |

---

### 01 没人可说 · 为什么你累得要死却睡不着
**内容**：睡不着 = 脑子不肯下班；车到家了发动机还在空转。深夜、失眠。
**感觉**：**深夜、暗、一个人熬**。

| 序 | 风格 | 为什么配 |
|---|---|---|
| 主 | **25 暮色窗光** | **暮色+窗光 = 失眠的标准画面** |
| 副 | **77 星夜** | 月亮星空 = "夜里只有月亮陪着" |
| 金句 | **47 逆光剪影** | 逆光人影 = 一个人在窗前的孤独 |
| 方法 | **53 光柱层次** | 光束穿透 = "给你一条路"（法子段） |

---

### 02 没人可说 · 你不是脾气变了
**内容**：火气一下就上来、那根稻草只是最后一下、装的地方满了。
**感觉**：**憋到了、要炸、但克制**。

| 序 | 风格 | 为什么配 |
|---|---|---|
| 主 | **46 霓虹描边** | **描边=边界感，情绪绷紧** |
| 副 | **37 大色块冲击** | **大色块 = "一下就炸"的爆发感** |
| 金句 | **99 藕荷紫** | 紫=尊严、克制 → "你不是脾气变坏" |
| 方法 | **108 思考气泡** | 自问自答 "火是冲这个事还是我憋着" |

---

### 03 没人可说 · 家里那个最沉默的人
**内容**：他一卸下来就不想说话、他在喘气、不是拒绝你。中国男人从小被教有事自己扛。
**感觉**：**沉默、疲惫、慢慢靠近**。

| 序 | 风格 | 为什么配 |
|---|---|---|
| 主 | **55 丁达尔光束** | **光束穿透黑暗 = 照进沉默** |
| 副 | **26 磨砂玻璃** | **隔着玻璃看 = "看不清他"** |
| 金句 | **61 玻璃后几何** | **他在玻璃后面 = 隔着一层** |
| 方法 | **95 薄荷绿** | 绿=平静安全 → "今天累不累"要温柔 |

---

### 04 我是不是没用了 · 退休那天起我就没用了
**内容**：退休半年人就垮了、空落落；法子=找一件别人等着你的小事。
**感觉**：**空、旧、慢、找回温度**。

| 序 | 风格 | 为什么配 |
|---|---|---|
| 主 | **58 玻璃光斑** | 暖光斑 = **旧日光、回忆感** |
| 副 | **78 雨窗** | 雨天玻璃 = "退休后一个人的下午" |
| 金句 | **63 长焦层叠** | 长焦压缩 = "回头看这一生" |
| 方法 | **88 云白叠层** | 亮净多层次 → "找个人让他等你" |

### 05 我是不是没用了 · 屋里安静得吓人
**内容**：一天说不了十句话、像一潭水不进不出慢慢混了；三个开口的法子。
**感觉**：**空房子、静得发慌、但要走出去**。

| 序 | 风格 | 为什么配 |
|---|---|---|
| 主 | **47 逆光剪影** | 空房里的一个人 = **"安静得吓人"最准** |
| 副 | **63 长焦层叠** | 层叠递退 = 空房间的纵深 |
| 金句 | **25 暮色窗光** | 一个人一窗光 |
| 方法 | **94 亮色几何** | 亮色几何 → "走出去、去有人的地方" |

### 06 我是不是没用了 · 我给孩子打电话没说两句就挂了
**内容**：打电话=有事、发语音=念叨；别只报喜不报忧，说一句"我这两天有点想你"。
**感觉**：**想孩子、轻轻的、隔着屏幕**。

| 序 | 风格 | 为什么配 |
|---|---|---|
| 主 | **114 重叠气泡** | **聊天记录层层叠 = 通话/语音最准** |
| 副 | **116 气泡串** | 气泡串 = **一条条语音发过去** |
| 金句 | **108 思考气泡** | 想说又不知道怎么说 |
| 方法 | **55 丁达尔光束** | 光照进来 → "别只报喜不报忧" |

### 07 你根本不了解我 · 孩子不说话不代表没事
**内容**：他一回家就关门、说"还行"；三个法子：问小的、坐着问、多听少说。
**感觉**：**柔、小心翼翼、心贴心的**。

| 序 | 风格 | 为什么配 |
|---|---|---|
| 主 | **111 心形气泡** | **心形 = 妈妈对孩子的心** |
| 副 | **115 心形叠层** | 心有厚度 = "他想说但不敢" |
| 金句 | **95 薄荷绿** | 绿=安抚 → "别急，他没事" |
| 方法 | **118 云朵叠** | 云=轻软 → "坐着问，别站着问" |

---

### 08 你根本不了解我 · 你越问他越不说
**内容**：第一句话就把门关上了；三句话——问"今天怎么样"、手机放下、"后来呢"。
**感觉**：**对话、一扇门、慢慢打开**。

| 序 | 风格 | 为什么配 |
|---|---|---|
| 主 | **116 气泡串** | **一问一答越来越小 = "他不说了"** |
| 副 | **114 重叠气泡** | 上一条说"还行"，下一条就没了 |
| 金句 | **108 思考气泡** | "后来呢" = 让孩子接着想 |
| 方法 | **88 云白叠层** | 干净步骤感 → 三句话 |

---

### 09 你根本不了解我 · 他考砸那天最怕的不是你骂他
**内容**：他怕的是"我这个人不值钱了"；说"你还是我的儿子/女儿"。
**感觉**：**最重、最戳心、孩子会掉泪**。

| 序 | 风格 | 为什么配 |
|---|---|---|
| 主 | **115 心形叠层** | **心有厚度 = "我怕我不值钱了"** |
| 副 | **111 心形气泡** | 心形里装着那句话 |
| 金句 | **78 雨窗** | 雨后玻璃 = "考砸那天"的下午 |
| 方法 | **92 亮彩柔光** | 亮柔光 → "你还是我的儿子"是光 |

## 三条线各自的"面孔"

| 线路 | 主视觉家族 | 观众感觉 |
|---|---|---|
| **A 没人可说** | 暮色窗光 / 霓虹描边 / 丁达尔光束 / 玻璃光斑 / 逆光剪影 | **沉、夜、一个人** |
| **B 我是不是没用了** | 玻璃光斑 / 逆光剪影 / 重叠气泡 / 心形气泡 / 心形叠层 | **空、旧、慢慢有温度** |
| **C 你根本不了解我** | 心形气泡 / 气泡串 / 心形叠层 | **柔、近、贴心** |

**C 线全是气泡家族**（心形+对话）→ 观众一看到气泡就知道"这是在讲孩子/沟通"；**A 线全是光影家族**（暮色/光束/窗光）→ 一看到就知道"这是在讲夜里一个人的心事"。**看风格就知道是哪条线。**
