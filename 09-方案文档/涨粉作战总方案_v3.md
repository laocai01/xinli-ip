# 第一部分 · 诊断：我们为什么不行（三层证据）

## 1.1 抖音官方给的数据（最硬）

| 指标 | 实测 | 意味着 |
|---|---|---|
| **前 2 秒跳出率** | **近 60%** | 10 个人进来 6 个在 2 秒内划走 |
| **平均播放时长** | **6.24 秒**（片长 119 秒） | 观众根本没进核心内容 |
| 官方归因 | **"缺少独立开篇，新用户看不懂、接不上"** | 开场讲"上一讲…"= 致命 |

## 1.2 我们片子实测（老马逐帧量，铁证）

| 秒 | 画面 | 变化量 | 问题 |
|---|---|---|---|
| 0-2s | 封面静置 | 0.0-5.4 | 黄金 2 秒给了不动的封面 |
| **5-8s** | 封面还在静置 | **0.0** | 连续 4 秒完全静止 |
| 9s | 才切真人 | 52.4 | 第 9 秒才见人 |

| 片尾 | 末尾 20 秒音量 | 问题 |
|---|---|---|
| A2 | -48 ~ -53 dB | 人声早没了，画面还挂真人脸上 |
| A3 | -48 ~ -51 dB | 同上 |
| B1 | -45 ~ -47 dB | 同上 |
| B2 | 末 8-12s 到 -59 ~ -78 dB | 几乎全静 |

**正常说话 -16~-19dB。片尾 20 秒只有 -48dB = 观众听 20 秒蚊子叫 + 看静止画面。**

## 1.3 ★ 最关键：2026 抖音算法已彻底改向（我们之前完全没跟上）

**权重排序（2026年4月起，慢推流机制上线）：**

| 旧算法（24小时） | **新算法（7天长效）** |
|---|---|
| 完播率 > 点赞 > 评论 | **收藏率 > 复访率 > 铁粉互动 > 5秒完播 > 评论质量 > 点赞** |

**实测权重数字**：
- **收藏率 ≈ 40%（第一）**
- **复访率 ≈ 25%（第二）**
- 收藏率+复访率+铁粉互动+主页访问深度 = **总权重 70%**
- **完播率滑落到第五位之后，点赞垫底**

**推流周期从 24 小时 → 7 天：**

| 阶段 | 天数 | 考核重点 | 我们要做 |
|---|---|---|---|
| 冷启动测试期 | 第 1-2 天 | **3 秒留存** | 别删视频（播得低正常） |
| **二次起量关键期** | **第 3-4 天** | **收藏数据上涨 → 自动第二波推流** | 主动引导收藏 |
| 长尾爆发期 | 第 5-7 天 | 收藏率+复访率 | 干货类 7 天总播放可远超首日 |

**这条改变了一切**：以前我们死磕完播率（所以把视频剪短），现在**该磕的是"让人收藏 + 让人回来看"**。

## 案例 1 · 「静候心声」— 20 万粉，火柴人 + 情感心理学 ★最可借鉴

| 项 | 内容 |
|---|---|
| **成绩** | 单条 **23 小时 159 万播放 / 5.82 万赞** |
| **形式** | 纯色背景 + 火柴人线稿，中英文字幕，AI 朗读（**无真人**） |
| **开头手法** | 「**这期视频是给已满 18 周岁的男孩子看的，刷到的女孩子们快艾特你宝宝来上网课吧**」→ **点名人群 + 呼唤转发**，一句话两个动作 |

| **固定模板** | 前 4 秒黑底白字标题 + 水滴音效 → 4-5 秒中英小标题两侧飞入 → 5 秒后正文（每句一图） |
| **作者原话** | 「**重要的是选题，不是画面**。我早期一些视频画面一般，照样能爆」 |
| **收藏密码** | 具体数字（"200ml 温水""54321 接地法""提升专注力 20-30%"）→ 观众收藏转发 |

# 第三部分 · 我们后边怎么做（可执行方案）

## 3.1 片子结构（新标准）

```
┌─ 0.0-1.5s  封面闪电版（1.5 秒，品牌 + 钩子大字）
├─ 1.5-4.5s  ★ 钩子句（真人开口第一句就是钩子）
├─ 4.5-7.0s  ★ 反常识结论（最反直觉那句）
├─ 7.0-10.0s ★ 共鸣体验（"你本来…结果…"）
├─ 10s-正文   正常展开（卡片按口播对齐，真人主轴）
├─ 高潮段     ★ 价值爆点（"记住这三点"式收藏点）
└─ 片尾       最后一句真心话 → 立刻切闭环（引导收藏+关注，不留空转）
```

**关键数字：**
- 封面 **1.5 秒**（从 8 秒砍）—— **第 1.5 秒必须听到人声**
- 钩子在 **1.5-4.5 秒**内说完
- **前 10 秒禁止"上一讲/上期/我们之前"**
- 片尾 **不留空转**，人声结束 ≤1 秒切闭环
- **总长 60-120 秒**（知识类甜蜜点）

## 3.2 钩子公式（七选一，每条必用）

| 类型 | 结构 | 我们的例句 |
|---|---|---|
| **① 痛点提问式** | "你有没有过____？" | 「你有没有过越想别难过，反而越难受的经历？」 |
| **② 反常识结论式** | "90% 的人都搞错了" | 「劝你想开点的人，正在让你更难受」 |
| **③ 互动体验式** | "现在你跟着我做：别想一只白熊" | 「现在你试一下：别想一只白色的熊」 |
| **④ 数字冲击式** | "99% 的人不知道" | 「情绪上来只有 4 秒机会，90% 的人都用错了」 |
| **⑤ 悬念式** | 半句话 | 「你以为你在忍，其实你在攒炸弹」 |
| **⑥ 身份点名式** | 直接叫人群 | 「正在学心理学的普通人，这条说给你听」 |
| **⑦ 警告避坑式** | "千万别____" | 「千万别劝人想开点，这会害了他」 |

## 3.3 ★ 内容设计五条新铁律（对齐 2026 算法）

### 铁律 1：每条必须"值得收藏"（收藏率 = 第一权重 40%）

**怎么做到：**
- 卡片做成**可截图保存的总结页**（"停退看做"四步一张图讲完）
- 内容里放**具体数字**（"4 秒""3 步""54321"）
- **结尾明确给收藏理由**：不是"记得收藏"，而是「**这条建议你收藏，下次情绪上来时对照着用**」
- 每期做成**系列**（"A线情绪自救 第N讲"）→ 用户收藏追更

### 铁律 2：必须引导"回来看"（复访率 = 第二权重 25%）

**怎么做到：**
- 结尾留**悬念预告**：「下一讲讲『____』，关注不错过」
- 主页**风格统一**（同一套视觉、同一主题线）→ 提升主页访问深度
- 内容做成**合集**（抖音"合集"功能，A线/B线分开）

### 铁律 3：抽象概念必须配具象画面（案例2 的密码）

| 抽象概念 | 具象化方案 |
|---|---|
| 白熊效应（越不想越冒出来） | 一只白熊在脑子里反复冒头 |
| 情绪四步（停退看做） | 红绿灯 / 刹车踏板 |
| 反刍思维（反复想同一件事） | 牛反复嚼同一口草 |

### 铁律 4：情绪 + 实用 = 黄金配比（案例7）

> 「没有情绪，内容再实用也难吃；全是情绪，那就是毒药」

我们的配比：**扎心共鸣 60% + 具体方法 40%**

### 铁律 5：每 10 秒一个新信息点（防划走）

- **第 5-8 秒完成信息点铺垫**
- **15 秒内完成第一个高潮情绪**
- **3-15-5 节奏**：3 秒代入感 → 15 秒高潮 → 5 秒余韵

## 3.4 互动引导（涨粉三件套）

| 目标 | 手法 | 具体做法 |
|---|---|---|
| **收藏率**（第一权重） | 给"收藏理由" | 「这条建议你收藏，下次情绪上来对照着用」 |
| **复访率**（第二权重） | 系列预告 + 主页统一 | 「下一讲讲『____』」；合集功能 |
| **评论率** | 提问式结尾 + 留槽点 | 「你有没有过……？评论区说说」；**故意留一个小争议点让人纠正** |
| **转发率** | 点名好友 | 「**@那个总劝你"想开点"的朋友**」 |
| **关注率** | 系列预告 + 人设 | 「我是正在学心理学的老蔡」 |
| **铁粉互动** | 回复评论 | 发布后 1 小时内回复前 10 条 |

## 3.5 发布与运营节奏（对齐 7 天慢推流）

| 时间 | 动作 |
|---|---|
| **发布后 0-30 分钟** | 集中拉完播（引导完整观看） |
| **30-60 分钟** | 引导评论互动 |
| **60-90 分钟** | 引导收藏和分享 |
| **第 1-2 天** | 冷启动期，**播得低正常，千万别删视频** |
| **第 3-4 天** | 二次起量关键期 —— **主动引导收藏**（评论区置顶精华评论，引导翻看） |
| **第 5-7 天** | 长尾爆发期，干货类可能远超首日 |

**发布时间**：抖音 12:00-13:00 或 **18:00-20:00**（晚 7-10 点最佳）

**标签**：2-3 个垂类（#情绪管理 #心理学）+ 1 个热点（#真实生活分享计划）

**必开原创声明**（原创多 2-3 倍流量）

## 3.6 自测流程（发布前必做）

### 人肉测试（10 分钟）
把**开头 10 秒**发给 **3-5 个不懂内容的朋友**，只给看前 10 秒，问：
1. 「你听懂我这条视频大概要讲什么了吗？」
2. 「你想不想继续往下看？」

**超过 2 人说"没看明白"或"不想看" → 重改开头，别发。**

### 机器测试（老马交付前必做）

| 检查项 | 判据 |
|---|---|
| 前 3 秒画面变化 | 逐帧变化量 > 2 |
| 前 3 秒有人声 | 音量 > -25dB |
| 封面停留 | ≤1.5 秒 |
| 片尾空转 | 人声结束后 ≤1 秒切闭环 |
| 片尾音量 | 闭环段 > -45dB（不静音） |
| 卡片动画 | 每张卡窗口内变化量 > 2 |
| 音轨 | duration=全片长、start=0 |
| 卡片对位 | 卡片出现时刻 = 口播说该内容时刻 |
| **收藏点** | **全片至少 1 处"值得截图保存"的总结卡** |

# 第五部分 · 合规红线（一条都不能碰）

- 禁心理治疗/精神障碍诊断（《精神卫生法》51 条）
- 禁疗效承诺、资质不实宣传、自称咨询师（《广告法》）
- 禁婚恋挽回/PUA
- 严禁词：咨询师/心理师/治疗/治愈/患者/抑郁症/焦虑症等诊断词
