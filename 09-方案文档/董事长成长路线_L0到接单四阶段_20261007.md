# 董事长成长路线：L0 → 能接单（四阶段）

**对象**：蔡志坤（「老蔡说」IP 出镜人 / 灵魂）
**起点**：L0 — 纯爱好者，正在学心理学，持有一个"不能马上赚钱"的证
**终点**：能接（付费）心理咨询单
**编制日期**：2026-10-07
**编制人**：大菊
**配套文件**：《平台调研_限流词与人设合规_20261007.md》（同目录）

---

## 0. 这份路线的两条腿

这份文档同时服务两件事，缺一不可：

1. **真成长** —— 董事长本人从爱好者走到能接单。
2. **真内容** —— 每一步成长都变成「老蔡说」的短视频选题。

**为什么必须绑在一起**：IP 的持续更新能力，来自"成长本身"。一个"正在学"的人的真实进展，是**别人抄不走的、无穷无尽的选题源**；而一个人已经学成之后，讲的东西反而会变成"教"，就不好看了。**"正在学"是这个 IP 最大的资产，不是过渡阶段。**

**所以本路线的设计原则是**：
> **不许偷偷学。每一步都必须先变成一条视频，再进入下一步。**

这不是为了做内容，而是因为：**"把学到的讲一遍"本身就是学习闭环里最有效的一环**（讲不清就是没懂）。两条腿是一条路。

## 1. 阶段总览（先看全景）

| 阶段 | 时间 | 一句话目标 | 里程碑 | 花费量级 |
|---|---|---|---|---|
| **阶段1** | 0-3 月 | 补伦理与基础，把"不能做什么"刻进骨头 | 通读伦理守则 + 完成伦理课 + 完成基础课 | 0 - 8000 元 |
| **阶段2** | 3-6 月 | 公益练手，攒够 50 小时 | 累计 50 小时公益服务时数（有记录） | 0 - 3000 元 |
| **阶段3** | 6-12 月 | 开始接受督导 | 稳定参与团督 + 找到个督 | 3000 - 15000 元 |
| **阶段4** | 12 月+ | 谈付费接单 | 具备可持续接单的资质、场地、法律与税务基础 | 5000 - 30000 元+ |

**四个必须知道的前提（写在最前面，防止跑偏）：**

1. **国家职业资格已取消（2017年）**。原"心理咨询师国家职业资格"已退出国家职业资格目录，**现在没有任何一个证书是"心理咨询行业的法定准入证"**。市场上的各类"心理咨询师证书"都是**培训合格证明**，不是执业许可。这决定了：本项目路径的合法性来自"合规地做心理健康服务"，不是"拿一张证"。
2. **心理咨询不是许可类业务**。海口嘉泰利贸易有限公司营业执照经营范围已含"心理咨询服务"（一般项目，非许可类）——**这就是本路径可以合法开展的基础**。
3. **红线不变**：不做心理治疗、不做精神障碍诊断治疗（《精神卫生法》第51条：心理治疗活动应当在医疗机构内开展）；不做疗效承诺。
4. **这条路线不能急**。行业内对新手接单的心理准备期普遍在 2-3 年。本路线的"12个月+"是**乐观但可行**的框架，实际可能更长。**任何阶段若感觉"被推着走"，停下来，这是伦理要求不是拖延。**

## 2. 阶段1（0-3 月）：补伦理与基础

### 2.1 一句话目标

**把"不能做什么"刻进骨头，比学"能做什么"重要十倍。**

心理咨询是个"做错事代价极大且不可逆"的行当——一句不当的话可能让一个人放弃求助。所以**伦理先行**，不是形式主义。

### 2.2 具体推荐

#### （1）伦理课（最高优先级，第一件事）

**推荐：徐凯文《心理咨询伦理》相关课程**

- **为什么是他**：徐凯文是北京大学副教授、临床心理学博士、**中国心理学会注册心理督导师（D-06-83）**、执业精神科医师；同时是中国心理学会临床心理学注册工作委员会及心理咨询师工作委员会委员。
- **课程依据**：该课程以 **CPS 临床心理注册系统《中国心理学会临床与咨询心理学工作伦理守则》（2018版，第二版）** 为纲。
- **形式**：市面有**视频录播课程**（半年有效期，电脑+APP 可看），也有线下 **3 天工作坊**（如 2026-08-28 至 08-30 有场次）。
- **内容覆盖**（据课程介绍）：保密原则、保密例外、知情同意、多重关系等——**全部是本项目的高频雷区**。
- 出处说明：以上信息来自课程承办机构的公开课程简章与媒体报道，属**培训机构公开信息**，非官方认定资质。**报名前请核实课程当前的官方主办方与开课信息**。

**替代/补充**：中国心理学会临床心理学注册工作委员会（CPS）体系下的伦理培训、各省心理学会或高校心理咨询中心开设的伦理课程。**判断标准只有一条：是否以 CPS《伦理守则（第二版）》为纲。**

#### （2）必读书目（按优先级排序）

**第一优先（必读，1 个月内拿下）：**

| 书名/文件 | 为什么必须先读 | 出处 |
|---|---|---|
| **《中国心理学会临床与咨询心理学工作伦理守则》（第二版，2018年2月）** | 这是本行业的"宪法"。全文含：总则 + 专业关系 / 知情同意 / 隐私权与保密性 / 职业胜任力和专业责任 / 心理测量与评估 / 教学培训和督导 / 研究和发表 / 远程专业工作（网络电话咨询）/ **媒体沟通与合作** / 伦理问题处理，共 **10 章 + 名词定义** | 心理学报 2018, 50(11): 1314-1322，官方期刊原文：https://journal.psych.ac.cn/xlxb/article/2018/0439-755X/0439-755X-50-11-1314.shtml |
| **《中华人民共和国精神卫生法》**（重点第51条） | 划定"能做什么"的法律底线。第51条：心理治疗活动应当在医疗机构内开展；专门从事心理治疗的人员不得从事精神障碍的诊断 | 主席令第62号，国家卫健委官网原文 |

> **划重点**：伦理守则里有一章叫「**媒体沟通与合作**」——**这一章是「老蔡说」IP 的直接行为规范**，请董事长第一阶段就精读，反复读。它规定心理师如何面对媒体、如何在公开场合谈论个案。我们虽然目前不是"心理师"，但**这正是我们要提前遵守的规范**，且它直接决定内容边界。

**第二优先（3 个月内）：**

| 书名/文件 | 用途 |

| **基础心理学与咨询理论教材**（普通心理学 + 发展心理学 + 异常心理学/变态心理学 + 咨询心理学导论） | 建立知识框架。异常心理学（讲各类心理障碍的部分）**是"必须懂但绝不能讲"的禁区**——懂它才知道边界在哪、什么时候该转介 |
| **CPS《临床与咨询心理学专业机构和专业人员注册标准》（第二版）** | 搞清楚行业内的"好"是什么样，避免被培训机构忽悠 |

**第三优先（贯穿全程）：**

| 书名 | 用途 |
|---|---|
| 关于"咨询如何起作用"的经典著作（各流派入门） | 形成自己的取向偏好。**不急，可以边练边定** |

> - 中科院心理所"心理咨询师基础培训"项目**已于 2024 年 6 月截止招收新生**（另有报道称 2025 年 6 月完成最后一次考试后正式停运）——**市面上仍在大力宣传该证书的机构，基本可以判定为虚假或滞后信息**。
> - 该证书曾被国务院点名整改（"存在易与国家职业资格认证混淆"的问题，涉及 13 家单位、共取得收入 3.47 亿元）。
> - 目前接续的路径是中国心理学会（CPS）与中科院心理所共同制定的 **《中国心理学会心理咨询师水平评价规范》**：必修课程 + 经 CPS 认定的培训机构和授课老师 + 全国统一线下考试 + 证书统一编号官网可查。

> - 出处：相关报道来自搜狐/环球网校等媒体的行业报道（**属媒体报道，非官方公告**），**报班前请务必自行核实项目的当前状态**。

#### （3）还有一个"必做"：开始记学习笔记

从第一天开始记，两个作用：

2. **是内容素材库**（见第 6 节对照表）。

### 2.4 判断达成的标准（怎么算真的过了）

不要用"我看完了"当标准，用**能不能说出来**当标准：

1. **抽查式自测**：能不看资料，向一个外行讲清这三件事——
   - 为什么心理咨询师不能给熟人做咨询？（对应"多重关系"）
   - 什么情况下咨询师必须打破保密？（对应"保密例外"，尤其是涉及伤害自己或他人时）
   - 为什么咨询师不能在视频里讲"我的来访者某某"？（对应"媒体沟通与合作"）
2. **红线测试**：能用《平台调研》第2节的"内容安全自检"9 条，当场判断一条陌生文案能不能发。
3. **笔记测试**：3 个月的笔记里，能找出 ≥ 20 条可直接转成视频选题的内容。

**能满足这三条，阶段1 就算过了。**

## 3. 阶段2（3-6 月）：公益练手，攒够 50 小时

### 3.1 一句话目标

**在"帮人不收费"的前提下，把耳朵练出来。**

### 3.2 为什么是 50 小时？（这个数字的意义）

**先说清楚：50 小时不是一个法定的门槛。** 国内没有任何法规要求"必须满 50 小时才能接单"。它的作用是**行业内的自我标尺**。

但在行业实操中，50 小时有非常具体的三重意义：

1. **它是"入门级可验证经验"的通行标尺。**
   行业内有共识：**每小时收费 200-300 元的，通常是"成长型"心理咨询师**（出处：新榜行业报道，R12）。而进入 CPS 注册系统的助理心理师评审路径，参照的时数量级是**咨询小时数 250 个、个体督导 ≥30 小时、团体督导**等（出处：行业整理文章，**属二手整理，非官方文件，需以 CPS 官方《注册标准》原文为准**）。
   → **50 小时是这条 250 小时路径的第一个 1/5 刻度**。它不让你"够格"，它让你**从"完全空白"变成"有过经验"**——这是找督导、进团体、被同行接纳的最低门票。

2. **它是"你到底适不适合做这个"的验证器。**
   很多人学到第三个月信心满满，真正在热线里听了 20 个小时之后，才第一次碰到自己的无力、烦躁、想逃。**50 小时足够让你遇到这件事。** 早遇到比晚遇到好得多。

3. **它把"我正在学"从一句自我介绍，变成可验证的事实。**
   对本 IP 尤为关键：账号里说"我在学"，和说"我做过 50 小时"，**可信度完全不同**。而且这 50 小时会自然产出大量真实故事，成为内容燃料。

> **一句话**：50 小时不是资格，是**"从想象进入现实"的必经通道**。

### 3.3 去哪里找这 50 小时？

按推荐度排序：

#### （1）12356 全国心理援助热线（首选）

- **来源**：**"12356"是国家卫生健康委协调工信部设置的全国统一心理援助热线电话号码**（出处：海南省安宁医院招募公告，官方公告）。
- **现状**：各省市由当地精神卫生中心/疾控精神卫生分中心承接运营，**且正在持续公开招募志愿者**。例如：
  - **海南省安宁医院（海南省精神卫生中心）**已发布 12356 心理援助热线志愿者招募公告——**本项目在海南，这是最近的落地通道，优先对接**。
  - 深圳市 12356 心理援助热线（深圳市康宁医院）长期招募夜班志愿者；上海市 12356 心理热线（上海市精神卫生中心等）也公开招募。
- **基本条件参考**（以海南省安宁医院公告为例）：遵纪守法、品行端正、无犯罪记录、有良好职业道德与团队合作精神、服从统一工作安排等；深圳公告中还提到年龄 20-50 周岁等。**具体条件以各地当期招募公告为准。**
- **为什么首选**：
  - 有**统一的培训与督导**（这是关键——公益不等于没人管）；
  - 有**规范的接线时长记录**；
  - 有**真实来电者**，且热线场景的边界清晰（接线 ≠ 咨询）；
  - **零成本**。
- ⚠️ **必须注意**：热线志愿者对资质/背景通常有要求（专业背景或相关培训）。**报名前先打电话或发邮件问清楚"我目前的情况能不能报""需要什么前置培训"**——不要因为怕被拒而不问。

#### （2）社区 / 学校 / 企业心理健康服务岗（公益向）

街道社区心理服务站、学校心理辅导中心、工会等常需辅助人员。**注意**：这类岗位往往要求"持证"或"专业背景"，能进入的角色可能是**辅助/行政/活动组织**而非直接咨询——**辅助也是时数积累的一部分**。

#### （3）公益心理服务机构的志愿者

各地有做公益心理咨询的社会组织。**筛选标准**（很重要）：
- ✅ 有督导机制
- ✅ 有明确的伦理规范与转介流程
- ✅ 有书面服务协议与记录要求
- ❌ 没有督导、只让你"上去聊"、把志愿者当免费劳力的 ——**不要参加**。这不是学习，是消耗，而且是伦理风险

#### （4）线上公益倾诉/陪伴平台

部分平台提供培训+接线机会。**筛选标准同上**：**看有没有督导，比看有没有平台重要。**

### 3.4 怎么记录？（50 小时的"凭证"怎么做才有效）

**这是最容易被忽略、但决定后续能不能过关的一环。** 一份不合格的记录，等于没做过。

**建议记录字段（每条服务一次）：**

| 字段 | 要求 |
|---|---|
| 日期 / 起止时间 / 时长 | 精确到分钟，**累计净服务时长**（不含等待、培训时间） |
| 服务形式 | 热线 / 线上 / 面谈 / 陪伴 / 辅助 |
| 服务对象标识 | **绝对不写姓名、电话、具体身份信息**——用编号（如"来电#071"） |
| 主题归类 | 极粗颗粒度：情绪低落 / 关系冲突 / 职业困惑 / 失眠…（**不写诊断性描述**） |
| 我做了什么 | 简述我的介入（如"倾听、复述、询问"） |
| 我遇到的困难 | **这一栏最重要**。这是要带去督导的问题 |
| 我自己的感受 | 我的烦躁/无力/想逃——**这一栏是做内容最珍贵的素材** |
| 督导/事后反馈 | 如果有督导，记录督导意见 |

**记录工具**：一个加密的表格（Excel 或笔记软件即可）。**关键要求：不记可识别个人身份的信息。**

**累计统计**：单独维护一张汇总表——累计小时数 / 累计服务人次 / 团督次数 / 个督次数。**这张表就是未来申请注册、进团体、谈接单时的"简历"。**

### 3.5 伦理注意（这一阶段最容易出事）

这是整个成长路线中**伦理风险最高的阶段**。原因很简单：**你终于开始"真的和人聊了"，而你的能力还没跟上你的热情。**

| 风险 | 具体表现 | 应对 |
|---|---|---|
| 🔴 **双重关系** | 在热线里接到亲戚、朋友、同事，或把自己的练手对象选成身边熟人 | **接到熟人立即说明并转介**（这正是最好的视频选题，见第6节）。**永远不给熟人做咨询** |
| 🔴 **越界到"治疗"** | 想"帮他彻底解决"，开始给方案、给建议、给判断 | 热线志愿者的角色是**倾听、陪伴、危机识别与转介**，不是治疗。**守住这个角色** |
| 🔴 **保密失守** | 把来电者的故事发到朋友圈/群里，或跟家人聊"今天接了个特别惨的" | **绝对禁止**。这既是伦理要求（守则"隐私权与保密性"章），也是本项目低调铁律的核心 |
| 🔴 **不能识别危机** | 来电者有自伤/自杀风险，志愿者试图自己处理 | **必须有转介预案**。12356 这类机构通常有危机处理流程，**上岗前务必问清并演练** |
| 🟠 **把服务对象变成内容素材** | "讲一个我遇到的案例" | **案例可以做内容，但必须彻底去标识、复合化处理**（把三个人的情况合成一个典型的），且**必须遵守守则「媒体沟通与合作」章**。**做不到"完全认不出是谁"就不要讲** |
| 🟠 **超时与耗竭** | 一口气接太多，自己先垮了 | **设定每周上限**（建议初期不超过 4-6 小时），允许自己休息。**这不是不够努力，这是专业要求** |
| 🟡 **无偿劳动被滥用** | 机构把你当免费劳力，不提供督导 | 及时退出。**没有督导的公益服务对成长是负资产** |

> **一句话原则**：**这一阶段你唯一要证明的能力，是"能安全地待在别人的痛苦里而不急着动手"。**

### 3.6 里程碑

- [ ] M2.1 确定 1 个有督导机制的公益服务渠道（优先 12356）
- [ ] M2.2 完成该渠道要求的岗前培训并通过考核
- [ ] M2.3 累计公益服务时数 **≥ 50 小时**
- [ ] M2.4 服务记录合规（不含可识别身份信息），累计表持续更新

> M2.5 看着奇怪，但它是这一阶段**最重要的达成标志**。50 小时没让你挫败过，说明你服务的强度不够，或者你在回避。

## 4. 阶段3（6-12 月）：找督导

### 4.1 一句话目标

**从"我自己觉得做得好不好"，切换到"有人告诉我做得怎么样"。**

**为什么督导是分水岭**：业余和专业的分界线不是知识量，而是**有没有第三只眼睛**。没有督导的"咨询"，无论多久，都只是在重复自己的模式。行业内看一个咨询师"专不专业"，第一眼看的就是**有没有接受督导、有没有持续的督导记录**。

### 4.2 两种督导，都要

#### （1）团体督导（团督）—— 先做这个

- **是什么**：一位督导师带 4-8 位受督者，轮流报个案，大家共同讨论。
- **形式**：通常线上（腾讯会议/Zoom）或线下，每周或每两周一次，每次 1.5-2 小时。
- **为什么先做团督**：
  - **便宜**（费用由多人分摊）
  - **有同伴** —— 新手最需要的不是答案，而是发现"原来大家都有同样的问题"
  - **听到别人的个案，等于免费学了别人的经验**
- **怎么找**：
  1. **通过第一阶段的伦理课/培训机构** —— 主办方往往有配套的团督小组，**这是最省事的入口**；
  2. **通过阶段2 的公益机构** —— 12356 等机构通常有内部督导；
  3. **通过 CPS 注册系统的注册督导师名单** —— 按"注册督导师"名录联系；
  4. 线上心理服务平台（如壹心理等）常有公开招募的督导小组。
- **筛选标准（重要）**：
  - ✅ 督导师本人有明确资历（如 CPS 注册心理督导师）
  - ✅ 小组有明确的设置（频次、人数、时长、保密规则、报个案轮次）
  - ✅ 有**受督伦理**（小组内讨论的内容同样保密）
  - ❌ 拉群就聊、没有设置的"督导" —— 不是督导

#### （2）个体督导（个督）—— 找一位固定的

- **是什么**：一对一，专门讨论我的个案。
- **形式**：通常每周或每两周一次，每次 50-60 分钟。
- **为什么必须要个督**：团督讨论的是"大家的个案"，个督讨论的是"**我的**问题"。**你自己最看不见的那个盲区，只有个督能指给你。**
- **怎么找**：同上四条路径，优先找能**稳定续约**而不是"约不到"的。

### 4.3 费用量级（如实说明）

**这是本路线最贵的一环。** 行业实际区间（来源见下）：

| 形式 | 量级 | 说明 |
|---|---|---|
| 团体督导 | **约 100 - 400 元 / 人 / 次**（2小时） | 由多人分摊，性价比最高 |
| 个体督导 | **约 400 - 1000 元 / 次（50-60分钟）** | 常见区间 |
| 高水平督导师（稀缺） | **可达 1500 元 / 人 / 小时**（团督中按人计） | 报道称"北京有教授做团督，每个学生一个小时收费 1500 元，每次 4 个学生一起，就是 6000 元，想约还不一定约得着" |
| 低价/公益团督 | **99 元 / 100 场**（特定公益项目） | 有平台推出过此类普惠项目 |

出处：心理行业媒体报道与平台公开信息（**属行业报道与平台宣传口径，非官方定价，仅作量级参考**）。

**本阶段（6-12月）的典型花法**：
- 团督：每两周 1 次 × 6 个月 ≈ 12 次 × 250 元 ≈ **3000 元**
- 个督：每月 1 次 × 6 个月 ≈ 6 次 × 600 元 ≈ **3600 元**
- **阶段合计：约 3000 - 15000 元**（取决于频次与督导资历）

> **省钱的三个办法**：
> 1. **公益机构的内部督导通常免费或极低** —— 阶段2 选的机构如果带督导，这里能省一大笔；
> 2. **团督优先于个督**（初期）；
> 3. **找普惠项目**（如 99 元 100 场那类），先攒经验再升级。

### 4.4 伦理注意

| 风险 | 说明 | 应对 |
|---|---|---|
| 🔴 **双重关系（在督导中）** | 把督导发展成朋友、或找熟人当督导 | 督导关系是**专业关系**，同样受守则"专业关系"章约束 |
| 🔴 **报个案时的保密** | 在团督里报了可识别个案信息 | 报个案同样是**保密场景**，须去标识化。小组全体成员对小组内容保密 |
| 🟠 **把督导当"上课"** | 期待督导给标准答案 | 督导不是教你"该说什么"，是让你看见"你为什么这么说" |
| 🟠 **只在团督不报个案** | 光听别人，自己从不报 | **必须报**。不报团的团督等于蹭课，成长有限，也是对小组的消耗 |
| 🟡 **督导与内容的边界** | 想把督导里学到的东西直接拿去做视频 | 可以讲**原理和方法**，**绝不能讲督导里讨论的个案细节**。且督导本身的内容也属保密范畴 |

### 4.5 里程碑

- [ ] M3.1 加入 1 个有正式设置的团体督导小组，稳定参与
- [ ] M3.2 **至少报过 3 个个案**（不是只旁听）
- [ ] M3.3 找到 1 位固定的个体督导师，建立稳定预约
- [ ] M3.4 建立"个案 + 督导"对照记录，能看出自己的重复模式
- [ ] M3.5 服务时数继续累计（本阶段目标：**累计 100-150 小时**）

### 4.6 判断达成的标准

1. 能说清**自己在咨询里最常犯的那一个错**（这是督导起作用的最直接证据）；
2. 能说出**自己的理论取向偏好**（不必定型，但要有倾向）；
3. 有一份**能被同行看懂的督导记录**（而不是只有自己的感受）；
4. **能在督导里承认"我不知道"和"我做错了"** —— 这一条其实最难，也最重要。

## 5. 阶段4（12 月+）：谈付费接单

### 5.1 一句话目标

**先合规，再收费。顺序不能反。**

**在谈任何"怎么赚钱"之前，先解决三个问题：**
1. 我有没有**资质上说得过去**的专业积累？（不是证书，是时数+督导+理论）
2. 我有没有**法律上站得住**的服务形式？（场地、协议、知情同意）
3. 我有没有**税务上做得干净**的收入路径？

### 5.2 资质门槛（如实说清）

**核心事实：心理咨询不是许可类职业，没有法定准入证。** 这意味着：
- ✅ **合法**：以"心理健康服务/情绪疏导/心理陪伴"的名义开展服务，主体是公司（营业执照经营范围已含"心理咨询服务"）或个体。
- ❌ **违法**：做**心理治疗**、做**精神障碍的诊断治疗**、开处方。《精神卫生法》第51条：**心理治疗活动应当在医疗机构内开展。**

**行业内的"资质"实际上是自我约束标准**，主要指：
- 接受的**系统培训**（长程项目，不是几天的工作坊）
- **咨询时数**（数百小时量级进入业内认可的讨论范围）
- **持续的督导**（注册路径参照值：个体督导 ≥30 小时、团体督导等）
- 可能的**注册**：中国心理学会临床与咨询心理学注册系统（CPS）的**助理心理师 / 注册心理师**，或中国心理卫生协会的职业能力水平评价

> 出处说明：上述时数参照值来自行业整理文章（**属二手整理，非 CPS 官方文件**）。**申请前必须以 CPS 官方发布的《注册标准》原文为准。**

**关于"能不能接单"的诚实判断**：
> 12 个月后，董事长大概率**具备"开始接单"的基础，但不具备"大量接单"的资历**。
> 更现实的做法是：**低定价（如 100-200 元/次）+ 高督导投入**——把接单当作"付费实习"，而不是收入来源。
> **行业内对成长型咨询师的定价共识是每小时 200-300 元**（出处：行业报道 R12）。**低于这个数说明还在练，高于这个数必须有相应的时数与督导支撑。**

⚠️ **特别预警（来自平台调研的发现）**：
抖音《心理咨询行业运营规范》（R4）要求做心理咨询类目小程序需具备 **3 位合作咨询师**的资格认证资质，且资质类型限定为：
- ① 心理咨询师国家职业资格证书（**该证已于 2017 年退出国家职业资格目录，此路径实际已关闭**）
- ② 中级以上精神卫生或临床心理专业技术职称，或接受过系统心理咨询专业训练 + 精神科执业医师资格
- ③ 应用心理学教学科研工作中级以上职称

→ **这三类资质都不是短期内能拿到的。** 意思是：**"在抖音上开小程序直接接单"这条路，门槛比想象的硬得多。** 届时更现实的方向是**与具备资质的资深咨询师合作**，董事长承担前端（内容/信任）角色，而非自己作为资质主体。**这一点建议在阶段3 就开始布局。**

### 5.3 平台选择

| 路径 | 优点 | 风险/门槛 | 建议 |
|---|---|---|---|
| **线下自有/合作场地** | 完全可控；合规最好把握 | 需场地与成本 | 🟢 **最优**：与已有资质的心理咨询机构合作，以"合作咨询师"身份在对方机构内服务 |
| **成熟心理服务平台**（如壹心理等） | 有流量、有平台审核、有伦理约束 | 平台审核资质；分成抽取 | 🟢 **推荐**：平台做资质审核，等于替我们做了合规背书 |
| **自建微信/小程序接单** | 无分成 | 需自建合规体系、支付、退款、隐私保护；**小程序类目对资质有硬要求** | 🟠 **谨慎**：现阶段不做 |
| **抖音平台内小程序** | 流量大 | R4 资质要求上述三类，**当前不满足** | 🔴 **现阶段不可行** |
| **私人微信直接收费** | 简单 | **无协议、无知情同意、无隐私保护、无税务**，纠纷时完全被动；且平台明令禁止引流 | 🔴 **绝对不做** |

**一条铁律**：**不做视频/站外引流成交**。
- 抖音 R1：禁止提供联系方式或站外引流；
- 视频号 R6 4.10.3：禁止"发布医疗相关内容并通过联系方式引流"。
- → **内容归内容，接单归接单，两条线物理隔离。** 曝光只用于建立信任，不用于导流。

### 5.4 法律注意

| 事项 | 要求 |
|---|---|
| **服务协议** | 必须有书面协议。明确服务性质（**是"心理健康服务"，不是"心理治疗"**）、次数、时长、费用、取消与退款规则 |
| **知情同意** | 首次服务前必须完成。明确告知：保密原则与**保密例外**（涉及自伤/伤人/法律规定时的处理）、服务范围与限制、**我不做什么**（不诊断、不治疗、不开药） |
| **保密与记录** | 服务记录加密保存，不含可识别信息；明确保存期限与销毁规则 |
| **转介机制** | **必须有**。识别到超出服务范围（疑似精神障碍、自伤风险）→ 立即建议其到符合《精神卫生法》规定的医疗机构就诊。这是法律要求（精神卫生法：心理咨询人员发现可能患有精神障碍的，应当建议其到符合本法规定的医疗机构就诊） |
| **保险** | 建议了解执业责任险。**未核实**国内该类产品的具体可得性与价格 |
| **服务资质表述** | **绝不在任何地方自称"心理咨询师"** ——这是资质不实宣传（《广告法》第28条），也是平台红线 |

### 5.5 税务注意

- **收款主体**：走公司账户（海口嘉泰利贸易有限公司，经营范围已含"心理咨询服务"），**不要走个人微信/支付宝收款**。个人收款在金额增大后有明确的税务风险，且无法开票、无法提供正规凭证。
- **发票**：对公客户/企业客户会要求开票，需公司主体。
- **个税/增值税**：收入需依法申报。具体税率与优惠政策**请咨询专业会计/税务师**——**本次调研未核实具体政策，不做猜测**。
- **记账**：从第一笔收入开始就记账，不要等到"做大了再说"。

- [ ] M4.2 完成服务协议 + 知情同意书模板（建议请专业律师审阅）
- [ ] M4.3 确定服务承接实体（优先：合作机构 / 成熟平台）

### 5.7 判断达成的标准

真正的"能接单"标准，不是"有人付钱了"，而是：

1. **能说清"我不做什么"** —— 比能做什么更能说明专业度；
2. **手上有转介名单** —— 知道遇到什么情况该转给谁；
3. **有保密例外预案** —— 想清楚了"如果他说要自杀，我怎么办"；
4. **每接一个案，都有对应的督导安排** —— 这是分界线。**没有督导配套的收费服务，无论有多少经验，都不建议开展。**

## 6. 【核心附件】「成长即内容」对照表

**这是本文件最重要的一节。** 每个成长阶段 → 对应的可直接做的短视频选题。**董事长的成长，就是 IP 的燃料。**

### 6.1 设计逻辑

为什么这张表有效：
1. **真实性是最大的护城河** —— 别人可以抄格式，抄不了"我真的在经历这件事"；
2. **成长是无限的** —— 只要还在学、还在错、还在困惑，选题就永不断货；
3. **它天然符合人设** —— "正在学心理学的普通人"的每一次翻车和恍然大悟，就是内容本身；
4. **它自带安全边界** —— 讲"我的学习/我的困惑/我的观察"，天然落在"情绪与生活"层面，不碰病理与承诺。

**一个必须守住的原则**：
> **讲"我"，不讲"他"；讲"我的感受"，不讲"他的病情"。**
> 一旦内容里出现一个具体的"某人"，就要立刻检查：这个人能被认出来吗？我在讲他的病还是讲我的收获？**任何可能让当事人被认出来的内容，一律不做。**

### 6.2 阶段1（补伦理与基础）→ 选题

| 成长动作 | 可产出的视频选题 | 形式建议 |
|---|---|---|
| 读《伦理守则》「专业关系」章 | **「学心理学第一课：为什么心理咨询不能给熟人做」** | 口播/图文，讲清"熟人做不了"的悖论 |
| 读「多重关系」 | 「如果朋友说'你不是在学心理学吗，帮我看看'，我该怎么回答」 | 情景式，自嘲：我学过之后反而更不能帮了 |
| 读「知情同意」 | 「第一次知道：原来找人聊心事之前，要先签个东西」 | 图文科普 |
| 读「隐私权与保密性」+「保密例外」 | **「咨询师说会保密，但有几种情况他会说出去」** | 信息型，这条天然有传播力 |
| 读「保密例外」中涉及伤害自己/他人的部分 | 「什么叫'我必须告诉别人'——关于保密的那条线」 | 严肃口播，注意不渲染 |
| 读「媒体沟通与合作」章 | **「我为什么不能把'我的来访者'讲给你听」** | 直接回应"你怎么不举例"的观众疑问 |

| 读异常心理学（**只学不讲**） | **「我读异常心理学这一章时的真实感受：越读越不敢乱说话了」** | 讲"我的敬畏"，**不讲具体病名** |
| 拿到/审视自己的证 | **「考了一个不能马上赚钱的证，图什么」** | **人设核心内容**，第一条就是这个思路 |
| 第一次发现"我给的其实是建议" | 「我以为我在共情，其实我在指挥」 | 自嘲翻车型，效果通常最好 |
| 学习笔记里的每一个"原来如此" | 直接就是选题 | 轻量产出 |

### 6.6 三条内容转化铁律

1. **讲"我的成长"，不讲"别人的问题"**
   每次想讲一个案例，先改成讲"我在那个案例里学到了什么"。

2. **讲"现象与感受"，不讲"病名与结论"**
   写完之后用《平台调研》第2.3节的自检清单过一遍。

3. **允许翻车，而且优先做翻车的内容**
   "我做错了什么"的传播力，永远大于"我做对了什么"。而且**翻车的内容才是真的**——这在人设上比"专家"更有生命力。
