**对照：旅游线的门槛**
| 业务 | 是否需要许可 | 门槛 |
|---|---|---|
| 心理咨询服务 | ❌ 不需要 | 无 |

> **结论：心理咨询这条线的资质门槛，比旅游低一个量级。** 这是它最大的优势。

### 2.2 两条硬红线（碰了出事）

| 红线 | 禁止内容 | 依据 |
|---|---|---|
| **① 不得做心理治疗 / 精神障碍诊断** | 不给诊断结论、不开处方、不建议用药、不做治疗、不宣称能治病 | 《精神卫生法》第51条；违者由卫健委处罚，构成犯罪追刑责 |
| **② 不得虚假宣传 / 承诺疗效** | 不写"包治好""几次根治""治愈率"；不自称"注册心理师/医生/治疗师" | 《广告法》；市场监管部门处罚 |

### 2.3 第三条隐含红线（平台规则）

- **不做婚恋挽回、恋爱教学、PUA 类内容**（抖音心理咨询类目明文禁止）
- **医学表述要替换**：抑郁症→情绪长期低落；治疗→情绪调适；患者→有困扰的人
- **案例必须去标识化**：任何个案内容不得可辨认到具体人

### 2.4 出镜身份怎么写（关键）

| ❌ 不能写 | ✅ 应该写 |
|---|---|
| 国家二级心理咨询师 | 心理学学习者 |
| 注册心理师 | 情绪陪伴 / 心理科普 |
| 专业心理咨询师 | 正在成长的心理学人 |
| 帮你解决心理问题 | 分享我学到的心理学知识 |

> 账号人设＝**初学者视角**。这既规避资质宣传风险，又是内容差异化的核心（见第五节）。

## 三、账号定位

### 3.1 一句话定位

> **「一个正在学心理学的人，把学到的东西讲给你听。」**

### 3.2 差异化在哪（同赛道对比）

| 类型 | 谁在做 | 优劣 |
|---|---|---|
| 专家科普号 | 成熟咨询师、心理学科普大V | 权威但同质化严重，已是一片红海 |
| 情景剧心理号 | 内容团队 | 制作成本高，人格化弱 |
| **成长型账号（我们）** | **几乎没有** | **成本低、粘性高、抗打、位置是空的** |

**为什么成长型账号抗打**：
1. **不用装专家** → 不触资质红线
2. **有追更黏性** → 观众追的是"一个人从0到专业"，像追剧
3. **选题无限** → 每天学什么、卡在哪、想通什么，全是素材
4. **成本极低** → 学习本来就该做，顺手拍就有内容

### 3.3 调性（三条铁律）

| 要 | 不要 |
|---|---|
| 扎心共鸣（说出观众说不出口的感受） | 搞笑（拿痛苦当笑料，平台限流） |
| 自嘲式幽默（"学了心理学我发现我妈更需要咨询"） | 专家说教（"你应该……"） |
| 真实（讲自己卡住的地方） | 完美人设（装全知） |
