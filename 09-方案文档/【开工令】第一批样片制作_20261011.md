## 三、硬规格（★ 与旧版不同处已标红字）

| 项 | 值 |
|---|---|
| 画幅 / 帧率 | 1080×1920 / 30fps（对齐源帧率，v=a） |
| **片头封面段** | **★ 取消（COVER_DUR = 0）** —— 第 0 秒真人开口 |
| **音频延迟** | **★ 不加 adelay**（封面段没了，音画天然对齐） |

| 卡片视觉 | 骨架不变（董事长铁律）；**卡片文字每条不同**；4.0s 动画；常显左上 LOGO |
| 结尾闭环页 | **★ 8s → 5–6s**（结论 + 要点 + 引导 + 涨粉，四层不缺） |
| BGM | 全程，**严格低于人声 6dB** |
| 字幕 | 按既有字幕规格；**结尾闭环页与封面页不叠字幕**（现有铁律） |
| 时长 | **不卡字数、讲明白为准**（董事长 2026-10-10 修订）；看完看清才切，压缩时长的建议一律驳回 |
| 作品封面图 | **★ 不单独做图** —— 发布时从视频里选「真人开口那一帧」 |
