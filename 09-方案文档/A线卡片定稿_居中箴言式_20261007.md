## 二、A线版式规格（六张卡统一）

### 只有 4 层（这是"不拥挤"的根本）

```
① 品牌条   老蔡说（LOGO + 楷体字，居中置顶）
② 主标题   引子行 + [焦点色块]（180-132px）
③ 辅助句   主标题下方 300px 处（54px 灰）
④ 签名     「正在学心理学的普通人·只说心事，不说教」（30px）
```

**砍掉的（这就是之前"挤"的根源）：**
- ❌ 左侧竖栏（大字核心词 + 竖线 + 竖排标签）
- ❌ 独立引子行（并入主标题第一行）
- ❌ 第二条分割线
- ❌ 底部"分享句"（只在收尾卡保留）

### 关键数值

| 项 | 值 | 说明 |
|---|---|---|
| 主标题字号 | **132px**（文字多的卡 118px） | 最大那行不超过 8 字 |
| 主标题行高 | **1.52** | 松，不压抑 |
| 主标题字距 | **8px** | 透气 |
| 焦点色块 | **独立成行** + `padding:10px 34px` | 前后不能紧跟别的字 |
| 主标题→辅助句间距 | **300px 空白** | 制造呼吸 |
| 辅助句字号 | 54px / 色 #7A7168 | 二次信息，弱化 |
| 边框 | 距画面 52px，`rgba(190,85,55,.28)` | 单细框，不要双框 |
| 背景 | 单层径向渐变光晕 | 去掉多层光晕+颗粒叠加 |

### 焦点色块两条硬规则（实测踩坑）

1. **`<em>` 前后不能紧跟别的字** —— 色块的 padding + box-shadow 会压住紧邻的字，观众看到残缺笔画（实测：「…同一件事**上**」的"上"被压掉大半个，看起来像"E"）
2. **`<em>` 要么独立成行，要么在行尾**
