# ★ 涨粉验收清单（2026-10-07 董事长三令五申：这是本IP的关键目的）

> 董事长原话：「这是我们制作心理咨询IP的关键目的，涨粉」「记得要做出有吸引力的视频。我们是要涨粉的」
>
> **涨粉 = 这个项目的唯一KPI。完播率、清晰度、卡片动效，全都服务于它。**

---

## 一、涨粉的底层逻辑（必须先想清楚）

**观众为什么关注一个号？**

| 原因 | 对应做法 |
|---|---|
| **① 这条有用，怕漏掉下一条** | 结尾留悬念 + 系列编号 |
| **② 这个人我认，想看他说什么** | 真人出镜 + 稳定人设 |
| **③ 这个号有体系，跟着能学完** | 分季分讲，连载结构 |
| **④ 同感"这说的就是我"** | 开场对号入座 |

**四条缺一条，涨粉就打折。**

---

## 二、每条成片必过的 8 项检查（缺一项打回）

| # | 检查项 | 判据 | 不过怎么办 |
|---|---|---|---|
| **1** | **封面有强钩子** | 封面大字是**反常识/冲突句**，不是描述句 | 重写封面文案 |
| **2** | **前3秒抓得住** | 第1句直接上钩，**无寒暄无铺垫** | 调整口播或封面 |
| **3** | **封面有系列标记** | 封面有「第 X 讲」 | 加上 |
| **4** | **卡片有唯一焦点** | 每张卡**只有1个**颜色色块 | 删多余的 |
| **5** | **卡片读得完** | 每条卡字数 ≤16 字（5秒能读完） | 砍文字 |
| **6** | **结尾指向下一条** | 最后一句明确说"下一条讲什么" | 补上 |
| **7** | **有身份锚** | 出现「正在学心理学的普通人」 | 补上 |
| **8** | **无硬喊关注** | 不出现"点关注/求点赞/关注不迷路" | 删掉 |

**为什么禁"硬喊关注"**：平台压 + 观众反感，反而掉粉。**用内容换关注。**

---

## 三、涨粉的"钩子四层结构"（每条口播都要有）

```
① 开场钩（0-3秒）  反常识 / 冲突断言  → 不划走
② 悬念钩（1/3处）  "但我后来才知道…"  → 想听下去
③ 方法钩（2/3处）  "记住这一句，今天就能用" → 觉得有用
④ 追更钩（最后）   "下一条讲…"        → 想关注看下一条
```

---

## 四、"连载感"是涨粉的最大杠杆

**让人感觉"这是一个连续的东西，断了就亏"：**

| 手法 | 具体 |
|---|---|
| 系列编号 | 每条说"这是第 X 讲"，封面也标 |
| 承上启下 | "上一条我说了…现在告诉你" |
| 明确指向 | "下一条讲：XXX" |
| 分季 | A线《跟自己的那场仗》/ B线《跟别人的那点事》 |

**效果**：单条视频的价值 ≈ 1；**连载的价值 = 每条的吸引力 × 观众"怕漏"的心理**。

## 五、发完必看的数据（判断该不该改方向）

| 指标 | 合格线 | 说明 |
|---|---|---|
| **完播率** | >30% | <10% = 内容或时长有问题 |
| **涨粉数** | >播放量的 0.5% | 1000播放涨5粉算正常 |
| **3秒留存** | >70% | 低于此 = 开场钩不够狠 |
| **点赞率** | >3% | 低 = 共鸣不够 |
| **评论数** | >5条 | 0评论 = 没戳到人 |

**留存分析需要播放量 >200 才能看** —— 所以**前几条的目标是先破 200 播放**。

---

## 六、如果数据不好，优先改这三处（按顺序）

1. **开场前3秒**（占问题 80%）—— 换成更冲突的断言
2. **封面**（决定点不点进来）—— 换更狠的钩子句
3. **时长**（太长会掉完播）—— 砍到 60 秒内试

**不要**先改卡片配色、动画效果（那些是锦上添花）。
