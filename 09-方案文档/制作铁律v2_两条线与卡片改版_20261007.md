## 三、卡片文字表现（董事长指出：现在的不吸引人）

**必须先学全网做法再改，不许凭感觉。** 已查证的设计规律（出处见文末）：

### 3.1 核心病因诊断（对照现有卡片）

| 问题 | 现有卡片 | 应改成 |
|---|---|---|
| **对比不足** | 字号接近、粗细接近 | **对比要胆大**：主标题字号是辅助文字的 2-3 倍以上（文字跳跃率 ≥200%） |
| **字数太多** | 一句话十几个字全上 | **只留 8 字左右核心词**做主体，占画面 50-80% |
| **缺焦点** | 每行一样重 | 用**颜色/大小/粗细**三重对比拉开层级，制造唯一焦点 |
| **关键词不突出** | 平铺 | 关键词**换色 + 加大 + 加粗**（现有只有"说"字这样做，不够） |

### 3.2 文字排版铁规

1. **一段话拆成 2-3 组**，多行排列，不要一整句平铺
2. **文字主体占画面 50-80%**（以单一长或宽衡量）
3. **色彩对比必用这几种**（高对比组合）：
   - 深色文字 + 浅色底
   - **白色文字 + 深色底**（如深蓝、深绿——这条正好用在"线路2冷色系"）
   - 彩色文字 + 白/浅底
4. **文字跳跃率要大** → 活泼热闹感（抖音要的就是这个，不要"高级安静感"）
5. **留白要狠**：主标题周围的空，就是它的力量
6. **描边/底色** 用于提升文字在复杂背景上的辨识度

### 3.3 钩子文案的心理学（9种技法，轮着用）

| # | 技法 | 我们可用的例子 |
|---|---|---|
| 1 | **好奇心驱动** | "心理学有个实验，结论跟你以为的完全相反" |
| 2 | **情感激发** | "你不是矫情，你是没被人教过怎么跟情绪相处" |
| 3 | **问题引导** | "你有没有过这种感觉——想了半天，人更累了？" |
| 4 | **反常识** | "越想越难受的人，不是想太多，是想错了一件事" |
| 5 | **个性化** | "我自己就是这样的人，所以我去学了心理学" |
| 6 | **特定性** | "3个信号，说明你在反复折磨自己" |

## 四、抖音「3秒」铁律（本次数据教训）

**实测：抖音播放170 / 完播率<3% / 平均播放<3秒 → 98%的人在前3秒划走。**

| 硬要求 | 判据 |
|---|---|
| 前 3 秒必须给"停下来的理由" | 卡片封面页钩子 + 真人开场钩子，**双钩** |
| 开场不许铺垫 | 不许"大家好""我是老蔡""今天聊聊" |
| 开场就有画面变化 | 卡片→真人的切换本身就是一个变化点 |
