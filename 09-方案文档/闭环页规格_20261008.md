# ★ 闭环页（片尾总结页）规格 v2 — 2026-10-08

> 董事长原话：「视频最后的闭环页。就是要把我们这一讲的内容做一个要点总结，让看到的人最后能够复习一遍并记住且能学到东西，同时又能引导下一讲，而且还能让最后的人点关注有助于我们涨粉」
> **董事长追加（关键）**：「这个闭环页没有描述该讲的结果是什么呀」

## 〇、v2 最重要的改动：必须有「结论」

**原来的闭环页只有要点，没讲"这一讲到底给了什么答案"——等于没讲完。**
修正后：**结论放在最上面，视觉最重（色块 + 最大字号），要点退居其次作为支撑。**

## 一、闭环页 = 结论 + 要点 + 引导 + 涨粉（四层，缺一不可）

| 层 | 内容 | 说明 |
|---|---|---|
| **① 结论** | **这一讲到底给了什么答案** | 一句话说出"结果"。**没有这个，页面等于没讲完** |
| ② 要点复习 | 2-3 条支撑结论的要点 | 让人"记住" |
| ③ 引导下一讲 | 预告下一讲题目 | 让人"追更" |
| ④ 涨粉 | 不硬喊的系列引导 | 让人"关注" |

## 三、硬规则

| 项 | 值 |
|---|---|
| **停留时间** | **7 秒**（内容比普通卡多，要给足读的时间） |
| **位置** | **最后一张**（原收尾卡的位置，替换掉） |
| **排版** | 沿用所属线的版式（A线居中箴言 / B线左栏分栏） |
| **编号色** | 焦点色（A线朱红 / B线亮黄），仅编号带色 |
| **要点数** | **3 条**（不超过3，多了记不住） |
| **字数** | 每条 ≤ 18 字 |
| **下一讲预告** | 必须有，用色块突出 |
| **涨粉话术** | 必须**不硬喊**（"跟上系列"而非"点关注"） |
| **LOGO** | 只留中间品牌条（左上角不叠） |
| **边距** | ≥80px；安全线 y=1620 |

## 四、四条片的闭环页内容

### 第03条 A线第1讲《想开点》
- 要点①：想不通不是你想错，是在原地打转
- 要点②：停下来，不是想通了，是不想了
- 要点③：问自己一句——最小的一步是什么
- 下一讲：**情绪一上来就想炸？先做这四步**

### 第04条 A线第2讲《情绪四步》
- 要点①：停——手离开手机，话别说出口
- 要点②：退——物理上离开这个场
- 要点③：看和做——看状态，做点别的
- 下一讲：**心里堵得慌的时候，有个更快的办法**

### 第05条 B线第1讲《追与躲》
- 要点①：他躲不是不爱你，是本能的保护
- 要点②：关键不是谁对谁错，是把动作说破
- 要点③：最后一句问"你需要多久"
- 下一讲：**躲的人，到底该说什么**

### 第06条 B线第2讲《你总是》
- 要点①："你总是"不是描述，是判决
- 要点②：换个开头，结果完全不同
- 要点③：三步——我看到/我感觉/我希望
- 下一讲：**吵到一半大脑断线，怎么办**

## 五、涨粉引导话术库（不硬喊，选一句）

**A线（跟自己的那场仗）：**
- 「跟上这个系列，下一讲还在这等你」
- 「这条线还长着，慢慢跟你聊」
- 「系列连载中，一讲解决一个事」

**B线（跟别人的那点事）：**
- 「这条线刚开始，一讲一个小办法」
- 「下一讲，我们接着说」
- 「跟上，我们一条条拆」

**禁用**：直接喊「点关注」「双击」「加关注」——平台不喜欢，人也不喜欢。
