> 董事长原话：「成片里，每讲的视频只保留一个完美真正用的，其他的全部删除」

## 一、目录规矩

**`E:\心理咨询IP\05-成片\` 只放"最终交付版"，一讲一个文件。**

```
05-成片/
├── 第01条_我考了个不能赚钱的证.mp4
├── 第02条_反刍.mp4
├── 第03条_A线第1讲_想开点.mp4
├── 第04条_A线第2讲_情绪四步.mp4
├── 第05条_B线第1讲_追与躲.mp4
└── 第06条_B线第2讲_你总是.mp4
```

**规则：**
1. **一讲只留一个 mp4** —— 最终版
2. **命名统一**：`第XX条_<线>第X讲_<主题>.mp4`
3. **不加 `_v2` `_v3` `_成片` `_最终` 等后缀**（那是过程稿的标志，过程稿不该出现在成片目录）
4. **过程稿一律放 `E:\心理咨询IP\04-工程\_过程稿\`**（或直接删）
5. **旧的、被取代的、试验的 —— 直接删，不留**

## 二、为什么

- 董事长要"一眼看出哪条是能用的"
- 多个版本并存 = 分不清、会发错、占空间
- 落盘的成果应该干净：**能用的就一个**

## 三、各目录职责（不要混）

| 目录 | 只放 |
|---|---|
| `05-成片/` | **最终交付的 mp4**（一讲一个） |
| `04-工程/` | 脚本 + 素材 + 中间产物 |
| `07-形象设计/卡片v2/` | 卡片源（html/png）+ 动画（动画/） |
| `素材/` | 董事长录的原片（不动） |
| `09-方案文档/` | 规范、方案、清单 |
