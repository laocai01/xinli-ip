## 六、★ 架构改版（2026-10-10 董事长定，覆盖旧「封面9秒」规格）

> 董事长原话：「我们不做封面，直接由我真人开讲，然后我们在整个视频的中间做文章」

| 项 | 旧 | 新 |
|---|---|---|
| 片头 0–9s | 静止大字封面段 + 只有 BGM | ❌ **整段取消** |
| 第 0 秒 | 无声静止图 | ✅ **真人开口，第一句就是强钩子** |
| 力气放哪 | 封面 | ✅ **中段**（每 25–30 秒一个钩 + 卡片视觉锚点） |
| 抖音「作品封面图」 | — | ✅ **单独上传一张大字钩子图**（不占片长，作用于列表页/推荐流） |
| 结尾闭环页 | 8s | ✅ 收到 **5–6s** |

**技术连带（是简化）**：`COVER_DUR = 0` → 音频 adelay 归零；卡片 overlay 用 `t_base = t`（**不再扣封面偏移**）→ 之前那批「卡片晚到 / 口型对不上 / 时基溢出」的坑整体消失。

**录制铁律**：**第一条录的第一句 = 成片第一帧**。开机后不要「好我开始录了 / 清嗓子 / 试音 / 低头看稿」，摆好直接开口 —— 否则等于把封面段换成了自己的废动作。
