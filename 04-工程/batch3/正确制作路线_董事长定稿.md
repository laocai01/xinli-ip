## 2. 素材与转录

### 2.1 素材盘点

- 手机竖录素材带 `rotation=90`，**真实显示是 1080×1920 竖屏**
- **必须用 ffprobe 一次读全**：`width / height / side_data_list[].rotation`
- `rotation in (90,270,-90)` → 显示尺寸是 (height, width)，即竖屏

### 2.2 转录

- 本机 faster-whisper small，模型在 `E:\工具环境\whisper\models`，**必须设 `HF_HUB_OFFLINE=1`**
- 输出结构：`[{"start":..,"end":..,"text":..}, ...]`，落 `03-内容/转录/<批次>/raw_N.json`

### 2.3 字幕校对（转录后第一件事）

| 环节 | 正确做法 |
|---|---|
| 校对立项 | **必须先出 `已校对字幕_N.json`**，绝不直接把 ASR 原文烧进画面 |
| 校对方法 | 逐句读；**只改明显同音错字，不改口播内容** |
| 判不准 | 标 `⚠待听`，切音频片段给董事长听；**不许擅自改词** |
| 繁简 | **繁体字占比必须 = 0**（>0 判转录异常，换模型重转） |
| 匹配技巧 | 转录词间带空格 → 替换时必须**先去空格标点再匹配**，否则匹配不上 |
| 复核 | 用 base + small 双模型交叉验证存疑处 |

**已知高频误识（实测）**：泪→累、收场→收藏、一磅→掰一半、間想→解决、
断根→断更、谎过→缓过、扶旁→复盘、棒拍→半拍、最善人→最扎人、画素→画数、
去闹疹→去医院、"打了三上打了"→"打了三个字又删了"。

### 2.4 素材命名

```
素材：<序号>_<线名>_<主题>_原片.mp4
转录：<序号>_<线名>_<主题>_转录.md
```

## 3. 真人画面

**正确做法（照做，别加东西）**
```
setpts=PTS/<speed>, scale=1080:1920:flags=lanczos, setsar=1, fps=30
```
ffmpeg 会自动应用 rotation，**不再自己 transpose**。

**只做尺寸确认，不裁剪、不调色、不加颗粒、不加暗角。**
董事长原话：「整个真人讲解的画面不做调整，就要原视频的」。

## 4. 字幕（2026-11-18 实测修订）

| 项 | 正确值 |
|---|---|
| **定位方式** | **`\an1`（左下锚）+ `\pos(58,1600)`**，文字从 pos 点向右展开 |
| 位置 | 固定槽位，**绝不滚动** |
| **动态** | **整句从下方 26px 升起 0.22s + 逐字淡入（每字 45ms）**，用 `\move` + `\t(\alpha)` |
| **句长下限** | 短句先合并，**每句 ≥1.2s**（否则逐字淡入跑不完） |
| 行数 | 任意时刻最多 3 行 |
| 断句 | **只按标点切**（，。！？、；：）；超宽才按语义停顿词拆 |
| 字宽 | 中文 = 字号 × 1.06；`SAFE_W=880`；最小 56 号 |
| 安全 | 左边距 **60px**（实测），最右 ≤958px；字顶 ≥1300 |
| 底部安全线 | y ≥ 1620 不放任何文字 |
| 字体 | `DouyinSansBold`（抖音美好体），96px 基准，超宽自动降号 |
| 颜色 | 暖金 `&H0066E0FF`，描边暖黑 `&H002A1A08` |
| 时轴来源 | **必须来自 ASR 逐句 cues**，不许按字数均分 |
| 滤镜 | **必须用 `ass=`**，且 `cd` 到 ass 所在目录再跑 |

**实测判据**：抽帧按字幕色（R>200, G>170, B<160, R−B>70）找像素，**距左应 ≥55px**。

## 5. 卡片

### 5.1 硬指标

| 项 | 正确值 |
|---|---|
| 几何 | 1080×1920 全屏原样铺满，禁止 crop / 缩放 / 只放一部分 |
| 张数 | 6–10 张/集，按内容锚点定 |
| 占比 | 真人 ≥60%；**任意 34 秒内最多 2 张** |
| 每张时长 | 动画 4.0s 播完 + 停留 3.0s = **7.0s** |
| 卡间 | 至少 1.2s 真人 |
| 首卡 | 不早于 3.0s（**0 秒必须真人开口**） |
| 片尾 | 留 8s 给收尾（关注 / 预告） |
| 铺满 | 卡片必须均衡铺满全片，不许堆在前半段 |

### 5.3 字符级动画库（12 种，同集内不重复）

`fadeUp` 逐字上浮 / `fadeIn` 逐字淡入 / `wipeL` 遮罩左擦 / `wipeU` 遮罩上擦 /
`typeOn` 打字机 / `spring` 回弹缩放 / `trackIn` 字距收拢 / `flyIn` 倾斜飞入 /
`byWord` 按词成组 / `pop` 弹出 / `sheen` 亮色扫过 / `drumRoll` 滚动落下

**顶层块动画**：`grow` 线生长 / `grow2` / `popBlock` / `maskRise` 遮罩升起 /
`slideL` / `slideR` / `scaleIn` / `blurIn`

**三条必须做到**：
1. 动画**贯穿全程**——实测判据：120 帧中唯一帧 **≥90%**
2. 落定后保持**极缓呼吸**（scale ±0.4%），不许出现死画面
3. 重点字最后出现，**到位后绝不再动**

## 6. BGM（咖啡厅感）

> 董事长原话：「不要老是放了却又听不见声音，要能听见但不能盖住真人讲解……
> 就像我们去咖啡厅喝咖啡一样，听着优美的音乐，同时也能正常的沟通聊天」

**唯一判据：BGM 要一直听得见，但人声永远是主角。**

| 项 | 正确做法 | 机器判据 |
|---|---|---|
| **电平** | 目标绝对电平 **−28dB** | 混音后 `说话段 − 最静处` 在 **8–12dB** |
| **校准方式** | **必须实测**：先量「人声说话段 P90」与「BGM P90」，反算增益 | 日志打印 `voice_speech_db / bgm_db / gain` |
| **处理链** | 只做轻度提亮：`equalizer=f=300:t=q:w=1.2:g=-1.5, equalizer=f=2600:t=q:w=1.0:g=+2.0` | — |
| **曲目** | **国际经典吉他名曲**（董事长：「要国际经典音乐，不能 AI 生成」） | — |
| 曲库 | `E:/心理咨询IP/06-音乐/国际经典_公有领域/` | — |
| 每集不同 | 6 集 6 首不重复，台账登记 | 同批曲目唯一 |
| 淡入淡出 | 首 2.5s 淡入、末 3.5s 淡出 | — |

## 7. 编码（手机可播是硬要求）

```
-c:v libx264 -preset medium -profile:v main -level 4.1 -crf 20
-maxrate 8M -bufsize 16M -refs 3
-x264-params keyint=60:min-keyint=60:scenecut=0:bframes=2
-pix_fmt yuv420p -r 30 -g 60
-c:a aac -profile:a aac_low -b:a 192k -ar 48000 -ac 2
-movflags +faststart
```

收尾必做：`scale=in_range=full:out_range=tv,format=yuv420p,setparams=range=tv:colorspace=bt709`

## 8. 交付标准（八步验收，全过才交）

| # | 检查项 | 判据 |
|---|---|---|
| 1 | 文件是新的 | 时间戳是今天，且不是 `.tmp.mp4` |
| 2 | 时长 | ≤180s（抖音上限），1:45–3:00 |
| 3 | 画幅 / 帧率 / 像素格式 | 1080×1920 / 30fps / yuv420p |
| 4 | 编码规格 | `profile=Main`、`level=4.1`、AAC 192k / 48k / 双声道 |
| 5 | **整片解码 0 错误** | `ffmpeg -v error -i x -f null -` 输出为空 |
| 6 | 音轨 | 音频时长 == 视频时长 == 总时长，`start_time == 0` |
| 7 | **真人占比** | 帧差法实测 ≥60% |
| 8 | **BGM** | `说话段 − 最静处` 8–12dB，最静处 ≥ −31dB |

### 8.1 抽帧目检（机器过完还要眼睛过）

- 开头 1 帧：人像朝上、左上角 LOGO、字幕在第 3 行区
- 每张卡 1 帧：文字完整、无孤字、无压字、署名在底部、点缀不抢字
- 片尾 1 帧：闭环 / 预告，不留真人空转
- **字幕逐句朗读一遍**（不是抽帧），与音频对照

### 8.2 一票否决

1. 未经董事长确认不得开跑成片
2. 前置素材必须到位（无素材不自造）
3. 给人看的东西必须清晰、能看明白
4. 看完看清才切换（卡片停留不压缩）
5. 原声原话一秒不剪

## 9. 检测方法与代码的注意事项

| # | 正确做法 |
|---|---|
| 1 | **找字幕必须按字幕色**：R>200, G>170, B<160, R−B>70；不能用亮度（白墙也亮） |
| 2 | **判卡片必须用帧差**：0.5s 两帧差 <0.6 = 卡片；不能用平整度（白墙也平整） |
| 3 | `clean()` 必须在**切标点之前**调用 |
| 4 | 改完脚本**必须核对输出文件是新的** |
| 5 | `moov atom not found` = 文件还在写盘，等进程退出再验 |
| 6 | **视觉模型读中文不可靠**，结论以像素 / 文本比对为准，视觉模型只判整体观感 |
| 7 | `setpts=PTS-STARTPTS+大偏移` 会溢出吞掉后续链 → 用 `tpad` 前置 |
