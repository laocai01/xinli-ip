# 📌 A线第4讲：《心里堵得慌，为什么劝自己想开没用》

**承接**：第03条结尾「下一讲…心里堵得慌的时候，给个更快的办法」｜**约 100 秒**

| 段 | 口播稿 |
|---|---|
| 🔥**钩子1** | 「心里堵得慌的时候，你是不是试过一个办法——使劲劝自己：别想了，想开点。」 |
| 🔥**钩子2** | 「结果呢？**越想开，越堵。**」 |
| 🔥**钩子3** | 「因为堵这个东西，你越堵它，它越硬。」 |

| **原理** | 「为什么有用？因为堵的时候，你整个人是"绷"着的。**身体一松，情绪才有地方走。**」 |
| **金句** | 「**情绪不是想通的，是走通的。**」 |
| 互动 | 「你堵的时候，一般会做什么？**评论区说说，我挑几条下期讲。**」 |
| 预告 | 「下一讲：**为什么有的人脾气特别大，一点就炸——那个"点"到底在哪。**」 |
| 签名 | 「我是老蔡，一个正在学心理学的普通人。」 |

**卡片**：①钩子卡「越想开/越堵」 ②方法卡「出声说一句/按胸口5秒/走三步」★ ③金句卡「情绪不是想通的/是走通的」 ④闭环页

# 📌 A线第5讲：《为什么有的人一点就炸——那个"点"在哪》

**承接**：接 A线第4讲往下讲｜**约 100 秒**

| 段 | 口播稿 |
|---|---|
| 🔥**钩子1** | 「你身边有没有这种人：一句话没说对，他就炸了。」 |
| 🔥**钩子2** | 「你以为是脾气问题。**其实炸的不是这句话，是这句话碰到了他一个旧伤。**」 |
| 🔥**钩子3** | 「就像手上有个地方破了皮，平时没事，可你一碰就疼得跳起来。」 |
| 转 | 「心理学把这种突然的过激反应，叫**"情绪按钮"**。」 |
| **核心** | 「每个人身上都有几个按钮。**按钮不是天生的，是小时候被按出来的。**」 |
| | 「比如小时候总被说"你怎么这么笨"，长大以后一听到"你不行"，立刻就炸。**他不是脾气差，是他那个旧伤口，又被碰到了。**」 |
| **方法★** | 「那该怎么办？记住一句话：**先按住你的嘴，问自己一句——"我炸的，是现在这件事，还是以前那件事？"**」 |
| | 「**只要能分开，火就小一半。**」 |
| **金句** | 「**你不是脾气大，你是有个地方还没好。**」 |
| 互动 | 「你身上有几个"按钮"？**评论区说说，最容易被哪句话点着。**」 |
| 预告 | 「下一讲：**情绪过去了，为什么你还是过不去——那个"回放"。**」 |
| 签名 | 「我是老蔡，一个正在学心理学的普通人。」 |

**卡片**：①钩子卡「一点就炸/炸的不是这句话」 ②核心卡「情绪按钮/是小时候被按出来的」 ③方法卡「我炸的是现在/还是以前？」★ ④闭环页

# 📌 B线第4讲：《吵到一半大脑断线，怎么办》

**承接**：第06条结尾「下一讲，**吵到一半，大脑断线，怎么办**」｜**约 105 秒**

| 段 | 口播稿 |
|---|---|

| **具象** | 「你的大脑里有个**警报器**。吵到激烈的时候，警报器拉响，它做的第一件事，是**把"讲道理的那个部分"断电**。因为它的目标是让你"打或逃"，不是让你"讲道理"。」 |
| **方法★** | 「所以吵到那种时候，**别硬讲道理，讲不通的。**做一件事——**喊停。**说："等一下，我现在说不出话，给我 10 分钟。"然后**真的离开 10 分钟**。洗个脸、走一圈都行。10 分钟后，你的大脑就回来了。」 |

| 签名** | 「我是老蔡，一个正在学心理学的普通人。」 |

**卡片**：①钩子卡「吵到一半/脑子一片空白」 ②核心卡「警报器拉响/把讲道理的部分断电」 ③方法卡「等一下/我说不出话/给我10分钟」★ ④金句卡「明明断电了/还在硬吵」 ⑤闭环页
