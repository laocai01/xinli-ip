# ⚡ 这四条按抖音 2026 新算法怎么设计的（先看这个）

## 新算法权重（我们对着打）

| 权重 | 指标 | 我们在脚本里怎么落实 |
|---|---|---|
| **①收藏率 40%** | 用户觉得"以后还要用" | 每条都有 ★可截图方法卡（具体到"握紧4秒""我看到/我感觉/我希望"这种**能照着做**的） |
| **②复访率 25%** | 人会回来再看 | 结尾**强预告下一讲**，且预告的是一个"具体的、有悬念的问题" |
| **③铁粉互动** | 评论+转发+关注 | 每条结尾**必留一个问题**让人想回答；A线第4讲直接引导转发 |

## "听得懂"三条硬规矩（写脚本时逐句执行）

| 规矩 | 反例（不能出现） | 正例（我们这么写） |
|---|---|---|
| **不用术语** | "这是投射性认同" | "**你听到的不是安慰，是"你难过是错的"**" |
| **一个概念配一个具象画面** | 只说"情绪会失控" | "**情绪从冲到顶，只有4秒**""**别想那只白熊**""**站在悬崖边**" |
| **每句不超过 25 字** | 长句套长句 | 短句，一句一个意思 |

## "想回来再看"三条硬规矩

| 规矩 | 做法 |
|---|---|
| **结尾留钩子** | 每条最后都预告"下一讲"，且是**悬念式问题**（"为什么越劝想开越堵"） |
| **系列感** | 开头用**观众视角承接**（"上一讲我教你四个字，很多人跟我说：停不住"）而不是"上期回顾" |
| **可收藏** | 方法卡做得像**卡片笔记**，一眼看懂、能截图 |

# ✅ 四条共性（录制+制作都按这个）

| 项 | 规范 |
|---|---|
| **开场** | 第 1 句就是钩子；**禁止"大家好""上一讲我们讲了"** |
| **承上启下** | 用"上一讲我教你…很多人跟我说…"这类**观众视角**过渡，不用"本期我们回顾" |
| **每 15 秒** | 一个信息点或情绪转折 |
| **收藏点** | 每条都有 1 张**可截图保存的方法卡**（★标记） |
| **互动引导** | 结尾必问一个问题（引导评论）或引导转发 |
| **预告** | 结尾留下一讲悬念（留人+复访） |
| **总长** | 95-120 秒（在 3 分钟内，且信息密度高） |
| **合规** | 不出现治疗/治愈/患者/抑郁/焦虑症等词；不自称咨询师 |

**录制提示**：语速稍快、有停顿（停顿要留 0.3-0.5 秒，给后期卡片留位）。
