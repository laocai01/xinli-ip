# 收官讲_讲完这二十讲我想跟你说句话

> 这二十讲，讲的其实都是同一件事

《讲完这二十讲，我想跟你说句话》

★ 这二十讲，讲的其实都是同一件事。
★ 不是你不够好。是你身边，没人接你的话。

（停一拍）
咱们从孩子讲起。
讲他摔门、讲他早恋、讲他玩手机。
讲着讲着，讲到你自己——
你在家说话，没人接。
你到家了不想下车。
你不敢生病，因为没人替你。
再往后，讲到你爸妈、你自己老了以后。
一个人吃饭、一双拖鞋、一辈子为谁活。

★ 你看，表面上是四五种人。
★ 底下是同一个东西：
★ 有话，没人说。
★ 有累，没人接。

我讲这些，不是要教你什么大道理。
（放慢）
★ 我自己也是个普通人。
★ 我也在车库里坐过，也说过"我没事"。
★ 我学这些，就是想知道，人到底卡在哪儿。
★ 我讲给你听，是因为我自己先被这些话说中过。

那这二十讲，我最想让你记住哪一句。
就三句，你带走。
★ 第一句：先说人，再说事。
——孩子、伴侣、爸妈，都是这一句。
★ 第二句：不会说，就递话。
——"我不问你，我就是有点担心你。"
（停一拍）
★ 第三句：你自己的那口气，也得有人接。
——你先说出来。你不说，永远没人知道。

我跟你讲，
人这一辈子，最怕的不是没人陪。
★ 是坐在一桌人中间，说了一句话，掉在地上，没人捡。
★ 你要是能当那个"捡话的人"。
★ 这个家就不一样了。

★ 说到底一句话：会说话的家，才住得下人。

★ 评论区打个数字，就一个数字：你最想让我下一批先讲哪一类——
1 孩子 2 夫妻 3 你自己 4 父母。
★ 我这批选题，就按你这个数字来定。你点哪个，我先讲哪个。
★ 这条你收藏一下，以后忘了就翻出来看看那三句。
★ 转给你家里那个"不会说话"的人——不用说啥，转过去就行。

我是老蔡，一个正在学心理学的普通人。
我把学到的、用过的，一句一句讲给你听。
下一批，就看你那一个数字。

【弹药出处】全批收束；20_婚姻「沟通邀请 Bid」；04_人本主义「无条件积极关注」；09_ACT「价值导向」；02_SFBT「应对问句」。

【三出口自检】
- 收藏出口：三句话（先说人再说事 / 不会说就递话 / 你也得被接住）
- 评论出口：**报数字选方向**（最強互动：既是评论，又是下批选题投票，还能制造"我参与了"的归属感）
- 转发出口：转给不会说话的人
- 目的：**收官 + 涨粉**（自我介绍+合集引导+投票式互动）
